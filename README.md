Rental Manager

Python Rental Management Application

This is a small practice project built with Python, focusing on managing rental-related data such as tenants, rooms, contracts, and expenses.
The goal of this project is to practice Python application structure, GUI development, and basic data handling.

Built for learning, experimenting, and portfolio purposes.

Features

Tenant management

Room / property management

Rental contract tracking

Expense & basic billing management

Report generation (PDF / CSV)

Simple and user-friendly GUI

Technologies Used

Python 3

CustomTkinter – GUI framework

Matplotlib – charts & statistics

ReportLab – PDF report generation

SQLite / Local storage

Other libraries listed in requirements.txt

📁 Project Structure
Rental-Manager/
│
├── assets/        # Images, icons, resources
├── controllers/   # Application logic
├── dashboard/     # UI screens
├── db/            # Database files
├── module/        # Feature modules
├── utils/         # Shared utilities
├── requirements.txt
└── main.py        # Entry point

How to Use
Install dependencies

Make sure Python is installed, then run:

pip install -r requirements.txt

Run the application
python main.py

Requirements

Python 3.9+

Windows / macOS / Linux

This project is not production-ready.
